# Ghostwriter — Microsoft Store 掲載情報（ja-JP）

## 製品名

Ghostwriter

## 短い説明

展開は浮かぶ。でも本文が進まない。AIと相談しながら、構想・資料整理・執筆・推敲をひとつの場所で進められる小説エディターです。

## 説明

展開やキャラクターは浮かぶのに、いざ本文にしようとすると手が止まる。Ghostwriterは、そんな書き手のためのAI小説エディターです。

思いついた場面の相談、プロットや設定資料の整理、本文の執筆・推敲まで、AIとの会話を中心に進められます。原稿や資料をチャットへ何度も貼り直したり、返ってきた文章を別のエディターへ移したりする手間を減らし、物語に集中できる執筆環境をつくります。

チャットモードでは、小説フォルダー内の原稿や資料を参照しながらAIと相談し、ファイルの作成や編集まで会話の流れで進められます。編集内容は適用済みカードで確認でき、必要な場合はUndoで元に戻せます。

自分の手で文章を整えたいときはエディットモードへ。本文を直接編集しながら、推敲・校正・ルビ候補などの単発AIアシストを利用できます。提案はApplyまたはRejectで確認してから反映します。書き上げた文章を通して確認したいときは、読むことに集中できるリーダーモードへ切り替えられます。

原稿と資料は、選択したローカルの小説フォルダーに保存されます。アプリ独自の保管場所へ移す必要はありません。

主な機能

- AIと会話しながら小説を書き進めるチャットモード
- 本文を直接編集し、AIの提案を確認して反映できるエディットモード
- 執筆した文章を読み返すためのリーダーモード
- 小説フォルダー内の原稿・設定・資料を参照したAIアシスト
- 適用済み編集の確認とUndo
- ローカルワークスペースによるファイル管理
- Codex（ChatGPTプラン）または各種AIプロバイダーAPIへの接続

AI機能の利用には、推奨のCodex（対応するChatGPTプラン。APIキー不要）、または対応AIプロバイダーのAPIキーが必要です。プロバイダーによっては利用料金が別途発生する場合があります。

## 製品の機能

以下は1項目ずつ登録します。Partner Center側で箇条書きになるため、先頭に記号は付けません。

1. AIとの会話を中心に執筆できるチャットモード

3. 本文を直接編集し、AI提案を確認して反映できるエディットモード

7. 新規小説のフォルダー選択と初期構成をまとめてセットアップ
8. Codex（ChatGPTプラン）に対応し、APIキーなしで接続可能
9. OpenAI、Gemini、DeepSeek、Anthropic、OpenAI互換APIに対応

## スクリーンショットの推奨順とキャプション

1. チャットモード — AIと相談しながら、構想から本文の執筆・編集まで進められます。
2. エディットモード — 原稿を直接編集し、AIの推敲・校正提案を確認して反映できます。
3. 適用済みカード — AIが編集した内容を確認し、必要ならUndoで元に戻せます。
4. リーダーモード — 余計な操作を減らし、書き上げた本文を読むことに集中できます。
5. ローカルワークスペース — 手元の小説フォルダーに原稿や設定資料を置いたまま利用できます。
