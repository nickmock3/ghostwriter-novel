# 245 表示の細部を整える（文字の切れ・設定画面・リーダーの見出し）

## 目的

UI確認で見つかった細かな表示の問題をまとめて直す。名前が途中で切れて読めない、設定項目の意味が分からない、同じ見出しが2回出る、といった引っかかりをなくす。

## 難易度

- 判定: 低
- 理由: いずれも表示だけの変更で、保存形式・API・AI実行に影響しない。個々の変更は小さく、互いに独立している。

## 背景

2026-10-09のUI確認で以下を見つけた。

| 箇所 | 現状 |
| --- | --- |
| ファイルツリー | 「章内プロット.md」が「章内プロット....」と切れ、全文を確認する方法がない |
| AIアシストのモデル選択（`AiAssistModelControls.tsx`） | 「DeepSeek V4 Pro」が「DeepSeek V4 Pr」と、省略記号なしで切れる |
| 設定画面「UI」（`src/features/settings/UiSettingsSection.tsx`） | 「ノイズディレクトリを表示する」に説明がなく、何が表示されるのか分からない |
| 設定画面「会話圧縮」（`ConversationCompactSettingsSection.tsx`） | スライダーの値「コンテキスト使用率 70%」が見出しより大きな文字で、スライダーから離れて表示される |
| リーダー（`src/features/reader/ReaderPage.tsx`） | 章タイトルが上部のバーと本文の見出しの2か所に表示される |

## 対象範囲

1. ファイルツリーの名前が切れる場合、マウスを乗せると全文が分かるようにする（`title`属性など）。
2. モデル選択の表示名が切れる場合は省略記号を付け、選択肢の全文を確認できるようにする。ペイン幅に余裕があれば、切れにくい幅にする。
3. 「ノイズディレクトリを表示する」に短い説明を付ける（例: 「`.git`、`node_modules`などの作業用フォルダもファイルツリーに表示します」）。項目名を分かりやすくしてもよい。
4. 自動圧縮のしきい値の表示を、スライダーの横または直上に、ラベルと同じくらいの文字の大きさで表示する。
5. リーダーの章タイトルの重複をなくす。本文の先頭行は原文そのものなので、上部のバー側の表示を変える（現在位置「第1章 / 全N章」など）か、片方だけにするかを実装開始時に決め、作業記録へ残す。仕様（章タイトルは`本文.txt`の先頭の空でない行から導出）は変えない。

## 対象外

- エディターのフォント・文字サイズの設定（今回はタスク化しない）。
- ヘッダー・サイドバーなどの文言統一（242）。

## 検証方針

- いずれも表示だけの変更で、実装を写したテストになりやすいため、原則として新規テストは追加しない。既存テストの成功と画面確認で検証する。
- リーダーの上部のバーの表示内容を変える場合は、表示する情報（現在の章番号など）が正しいことを`ReaderPage`のテストで確認する。
- 画面で、狭いペイン幅でのファイルツリー・モデル選択の表示、設定画面、リーダーの見出しを確認する。
