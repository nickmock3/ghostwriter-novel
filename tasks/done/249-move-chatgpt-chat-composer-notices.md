# 249 チャットの接続案内を入力ボックスの外に移す

## 難易度

- 判定: 中
- 理由: チャットの接続状態を既存のセッションからサイドバーへ反映する。表示条件、キーボードでの案内とAIアシストへの影響を確認する。

## 対象と完了条件

- 利用可能なChatGPT接続のチャットでは、サイドバー下部の設定ボタンの上に利用状況ページへのリング状のアイコンを置く。公式連携で使用率を取得できないため、リングに割合は表示しない。
- モデル固定の説明文を常時表示から固定中のモデル名のツールチップに移す。既存会話の接続・モデル選択欄の無効化を維持する。
- 利用中の表示条件、上限時の復旧リンク、モデル固定、AIアシストの配置を維持する。

## 検証方針

- 既存Playwrightで、利用状況リンクがサイドバーに表示されること、チャット送信後にモデル選択が固定されることを検証する。先行テストでは、従来の利用状況リンクが入力フォーム内に残るため失敗することを確認済み。
- UIの表示と配置はPlaywrightで確認し、同じDOM断面を別の新規テストファイルで重複検証しない。型チェックとVitest全体も実行する。

## 検証結果

- `bun run test -- --maxWorkers=2 --testTimeout=60000` は1258件成功、既存2件スキップ。最終調整後のSIWC接続・Appテストは52件成功。`bun run typecheck` は成功。
- `bun run test:e2e -- e2e/siwc-workflow.spec.ts --workers=1 --trace=retain-on-failure` は成功。接続時のサイドバーリンク、APIキー接続時の非表示、固定モデルのツールチップとアクセシブルな説明、AIアシストの表示を確認した。チャットのスクリーンショットで入力欄とサイドバー下部の配置を確認した。
- デスクトップのネイティブ境界と外部API契約に変更はなく、MSIXの再ビルドと実アカウント検証は未実施。
